Quali-D WhatsApp

Send approved WhatsApp Business templates straight from Odoo

Features

  • Automation Rules — new action type Send WhatsApp (Quali-D): order confirmed, lead won, invoice due… any trigger.
  • Variable mapping — fill {{1}}, {{2}} from any field, including related fields (partner_id.name).
  • Media headers — image, video and document templates.
  • Background queue with automatic retries — saving a record is never slowed down.
  • Send once per record — no duplicates when a rule fires twice.
  • Manual send from contacts (single or bulk), or any model via a contextual action.
  • Chatter note on the record and a complete message log.
  • Secure — revocable, rotatable Quali-D tokens; the token is never logged.

Setup in 3 steps

  1. In Quali-D open Settings → Odoo Connector and generate a token.
  2. In Odoo open Settings → Quali-D WhatsApp, paste the token, click Test Connection then Sync Templates.
  3. Create an Automation Rule, add an action of type Send WhatsApp (Quali-D), pick a template and map its variables.

Requires a Quali-D account with a connected WhatsApp Business number. quali-d.com
