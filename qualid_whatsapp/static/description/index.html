WhatsApp for Odoo, by Quali-D

Send invoices, reminders and updates on WhatsApp — automatically

Send your approved WhatsApp Business templates from any Odoo record. Invoices go out with their PDF attached, payment reminders send themselves, and every message is logged on the record. Set up common automations in one click — no code.

One-click automations

Pick a ready-made automation and a template. The trigger, the filters (for example customer invoices only), the PDF and suggested variables are filled in for you.

The Automations list in Settings → Quali-D WhatsApp. Recipes for apps you haven't installed are marked “Install …”.

Invoices, quotations and more — with the PDF attached

Templates with an image, video or document header get their file automatically: the PDF Odoo prints for the record (invoice, quotation, delivery slip, purchase order…), its latest attachment, an image from the record, or a link.

Works with any Odoo automation

Send WhatsApp (Quali-D) is a new action type, so it works with every model and every trigger — including your own apps and Studio models. Map template variables to any field, following links with dots (partner_id.name).

Built to be reliable

  • Background sending — confirming an invoice never waits for WhatsApp.
  • Automatic retries when the network or WhatsApp is briefly unavailable.
  • Never twice — each automation sends once per record, and every send carries an idempotency key.
  • No broken messages — a missing phone number or an empty variable stops the send with a clear reason, instead of sending something wrong.
  • Full log — a note on each record and a message list with status and errors. Failed messages can be retried.
  • Manual sending — ⚙ Actions → Send WhatsApp Template on contacts, for one or many.
  • Templates sync automatically from Quali-D, every hour.
  • Secure tokens — create, rotate or revoke Odoo tokens anytime in your Quali-D dashboard.

Set up in 3 steps

1

Create a token
In your Quali-D dashboard: Settings → Odoo Connector → New Token.

2

Paste it in Odoo
Settings → Quali-D WhatsApp → save. Your templates are imported automatically.

3

Pick an automation
Click Set up next to a recipe, choose the template — done.

Good to know

  • Requirements: a Quali-D account with a connected WhatsApp Business number and approved templates — quali-d.com.
  • Odoo Online (SaaS): modules with code can't be installed there. Use the no-install webhook method from your Quali-D dashboard (Settings → Odoo Connector) instead.
  • Files: PDFs, attachments and images sent from Odoo are uploaded securely to Quali-D so WhatsApp can deliver them, and stay available in your Quali-D conversation history. Limits: images 5 MB (converted to JPEG automatically), videos 16 MB (MP4/3GP), documents 100 MB.
  • WhatsApp rules apply: only approved templates can be sent, and marketing templates should only go to customers who agreed to receive WhatsApp messages.
